# 服务端控制台与日志

启动独立服务器后，输入命令并按回车执行。空行不执行操作；`stop` 或 Ctrl+C 正常关闭，单独按回车不会退出。命令不区分大小写，可以带 `/` 前缀。

| 命令 | 用途 |
|---|---|
| `help` | 查看帮助 |
| `players` | 列出 UID、名字、房间，未入房显示大厅 |
| `rooms` | 列出房间码、房主、人数和加入开关 |
| `kick <uid>` | 断开玩家连接，客户端显示管理员踢出提示 |
| `leave <uid>` | 移出房间，保留连接；移出房主会解散房间 |
| `maxplayers [人数]` | 查看或设置服务器上限，范围 1–256 |
| `say <内容>` | 以服务器身份向所有在线玩家发言 |
| `stop` | 关闭服务器 |

管理命令只从服务端本地控制台调用，不向普通客户端开放。使用 UID 指定玩家，不支持地图传送或强制加入其他房间。

降低人数上限保留在线玩家，只限制后续连接；房间上限不自动改写。修改仅对本次运行有效，重启仍使用启动参数。标准输入结束时继续运行，不把 EOF 当作关闭命令。

`say 大家好，欢迎来到服务器` 会向大厅和所有房间广播。客户端显示“服务器”，不生成角色气泡。正文保留内部空格，不需要引号；长度和敏感词检查与玩家聊天相同。聊天正文日志仍受 `logChat` 控制。

## 日志

控制台输出带时间、时区和级别的日志，同时追加到程序目录的 `logs/启动日期.log`，同日重启继续追加。文件按每次启动的日期命名，跨日运行不切换文件。

记录上线、下线、改名、房间操作、管理操作、聊天拒绝和回调异常。不逐条记录运动、心跳或玩法消息。连接关闭只记录实际原因，不猜测是否主动退出。

将输出目录的 `server.example.json` 复制为 `server.json`：

```json
{
  "logChat": false
}
```

`logChat` 默认关闭，设为 `true` 后记录通过检查的聊天正文与发送者 UID、名字。拒绝的敏感词原文不记录。玩家文本的换行和终端控制字符会被转义，避免伪造日志行。

配置启动时读取；缺失时使用默认值，JSON 无效时启动失败。实际配置不提交 Git。聊天过滤继续使用独立的 [`chat-filter.json`](server-chat-filter.md)。

独立进程使用控制台与文件输出，不初始化 BepInEx；游戏模组的日志继续使用 AutoLog。
